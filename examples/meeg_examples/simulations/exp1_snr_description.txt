=== Эксперимент 1: Влияние SNR на топологический поиск источников ===

Файл: exp_snr.py

Описание:
Этот скрипт исследует влияние отношения сигнал/шум (SNR) на качество извлечения целевого источника с помощью топологических фильтров (fit_filters, UMAP). Для оценки используется базовая линия (baseline) — метод ICA с алгоритмом Picard, который часто применяется в ЭЭГ/МЭГ данных.

Методология:
1. Варьируется значение SNR (от -1.4 до 1.0 в логарифмическом масштабе, шаг 0.2).
2. Для каждого уровня SNR проводится Монте-Карло симуляция (по умолчанию 2 итерации, но рекомендуется увеличить до 5-10 для сглаженных графиков).
3. В каждой симуляции генерируется распределенный целевой источник и фоновая активность (100 источников всего).
4. Данные проецируются на сенсоры (через fsaverage-fwd.fif) с заданным уровнем шума.
5. Для UMAP (fit_filters): ковариационные матрицы отображаются в 3D пространство (N_dim=3). Мы берем ту компоненту, которая имеет наивысшую корреляцию с истинным паттерном целевого источника.
6. Для ICA: алгоритм Picard выделяет 15 компонент. Мы находим ту, которая имеет наивысшую корреляцию с истинным паттерном целевого источника, и вычисляем ее временную мощность (огибающую).
7. Скрипт строит графики абсолютной корреляции Пирсона для паттернов и мощности и сохраняет в `exp1_snr_results.png`.

Параметры для настройки (внутри файла exp_snr.py):
- `n_mc_iterations`: Увеличьте до 5 или 10 для публикации/препринта.
- `epochs` внутри `fit_filters`: Увеличьте до 300-500 для лучшей сходимости фильтров (сейчас уменьшено для скорости тестов).
- `snr_logs`: Массив проверяемых SNR.

Как запустить:
`python examples/meeg_examples/simulations/exp_snr.py`
